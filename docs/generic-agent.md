# Spec with Any Coding Agent

- Run `spec install`
- Restart the coding agent or VS Code
- Ask `spec init` inside the agent
- Then ask `spec <what you want to build or change>`
- Require the agent to read `.spec/` and follow `.spec/SKILL.md`
- Require the agent to do domain research, work classification, impact review, tests, rollback and memory update before the final prompt

Spec does not replace your agent. It hardens the project context around it.
Spec helps vibecoding by giving the agent a safer decision pipeline.
