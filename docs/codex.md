# Spec with Codex

- Run `spec install --codex`
- Restart Codex or VS Code
- Ask `$spec init` inside Codex
- Then ask `$spec <what you want to build or change>`
- Make sure Codex reads `.spec/` and follows `.spec/SKILL.md`
- Make sure Codex does domain research, work classification, impact review, tests, rollback and memory update before the final prompt

Spec does not add automation inside Codex by itself.
Spec is not anti-vibecoding. It helps Codex start from safer decisions.
