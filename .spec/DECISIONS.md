# Decisions

## Current Decisions
- Record important product and architecture choices here.

## Decision Ledger Format

Use this format for important choices:

```md
## Decision: <title>

Date: YYYY-MM-DD
Status: proposed | accepted | revisited

### Context
<What forced this decision?>

### Decision
<What was chosen?>

### Why
<Why this is the safest useful choice now?>

### Tradeoffs
<What this makes easier and what it postpones?>

### Revisit If
<Signals that should trigger a new decision>
```

Record decisions about stack, folder boundaries, auth, permissions, data ownership, statuses, integrations, validation, rollback, refactors and major scope deferrals.
